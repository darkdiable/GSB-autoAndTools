# VLPR 车牌号提取工具

基于 Python 的车牌号自动识别工具，采用模块化设计，支持多种常见车牌颜色（蓝、绿、黄）的识别。

## 功能特性

- 自动读取 vlp 目录下的所有汽车照片
- 支持蓝牌、绿牌、黄牌等多种车牌颜色
- 自动过滤非汉字/字母/数字的干扰字符
- 完善的异常处理机制
- 未检测到车牌时返回"无车牌信息"

## 依赖安装

### 方式一：使用 HyperLPR3（推荐）

HyperLPR3 是一个高性能的中文车牌识别库：

```bash
cd VLPR
pip install -r requirements.txt
```

### 方式二：仅使用 OpenCV（备选）

如果 HyperLPR3 安装失败，程序会自动降级使用 OpenCV 进行车牌区域检测：

```bash
pip install opencv-python numpy
```

## 目录结构

```
VLPR/
├── main.py                    # 主程序入口
├── requirements.txt           # 依赖包列表
├── README.md                 # 说明文档
├── src/
│   ├── __init__.py
│   ├── license_plate_recognizer.py  # 车牌识别核心模块
│   └── char_filter.py        # 字符过滤与验证模块
└── vlp/                      # 存放待识别的汽车照片
    ├── 图1.jpeg
    ├── 图2.jpg
    └── ...
```

## 使用方法

1. 将待识别的汽车照片放入 `vlp` 目录
2. 运行主程序：

```bash
cd VLPR
python main.py
```

## 输出格式

```
==================================================
车牌识别结果
==================================================
图1.jpeg ： 京A12345
图2.jpg ： 沪B67890
图3.jpeg ： 无车牌信息
==================================================
```

## 模块说明

### 1. LicensePlateRecognizer（车牌识别核心模块）

主要功能：
- 基于颜色检测车牌区域（蓝、绿、黄）
- 基于边缘检测的备选方案
- 集成 HyperLPR3 进行字符识别
- 异常处理机制

### 2. CharFilter（字符过滤模块）

主要功能：
- 过滤无效字符（仅保留中文、字母、数字）
- 验证车牌格式有效性
- 提取最优识别结果

## 支持的车牌类型

- 蓝牌：普通小型汽车
- 绿牌：新能源汽车
- 黄牌：大型车辆、教练车等

## 注意事项

1. 建议使用清晰度较高的图片
2. 车牌应位于图片中心且无严重遮挡
3. HyperLPR3 首次运行时会自动下载模型文件
